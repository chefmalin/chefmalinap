# ChefMalin — étape 1

Écran d’accueil responsive de ChefMalin (NutriChef), avec les interactions de démonstration demandées.

## Lancer l’application

Dans ce dossier, exécutez :

```powershell
npm start
```

Puis ouvrez `http://localhost:4173` dans votre navigateur.

## Ressources

- `assets/pipo-reference-crop.png` est un cadrage de Pipo réalisé à partir de la maquette de référence fournie. Il ne remplace pas un fichier source original avec fond transparent ; il pourra être remplacé directement lors de sa livraison.
- Les trois recettes dans `index.html` sont volontairement identifiées par le commentaire `DEMO_RECIPES` et sont des visuels de démonstration.
